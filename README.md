# StudySnap AI

StudySnap AI is a Streamlit-based study assistant that helps students understand educational content using Gemini AI.

## Features

- Ask study-related questions
- Upload images of notes, textbook pages, diagrams, and questions
- Get simple explanations using Gemini Vision
- Continue with follow-up questions
- Send a study summary to email

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- Gmail SMTP

## How to Run Locally

1. Create and activate a virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
3. Add your secrets inside .streamlit/secrets.toml.
4. Run:
streamlit run app.py


Then save it with **Ctrl + S**.
